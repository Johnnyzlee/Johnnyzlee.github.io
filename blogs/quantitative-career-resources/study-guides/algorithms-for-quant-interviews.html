中文精编版：把算法题按可复用模式组织，适合量化研究编程面试前快速复习。每道题的完整答案应包含正确性理由、时间复杂度、空间复杂度和边界情形；English 页面保留更完整的扩展模板。

优先级： P0 = 必须能默写；P1 = 常见扩展；P2 = 专题技巧。数位归约和区间合并均列为 P0。

0. 面试作答流程

  1. 澄清： 输入输出、规模、是否有序、重复值、能否修改输入、内存限制、精确或近似答案。

  2. 举例： 手算一个正常例子和一个边界例子。

  3. 基线： 先说明暴力解及复杂度，再谈优化。

  4. 识别模式： 哈希、排序、双指针、滑窗、栈、堆、图、贪心或动态规划。

  5. 不变量/状态： 解释每轮后什么始终成立，或 dp[state] 的含义。

  6. 编码： 逻辑与 I/O 分开；短变量名只用于标准下标。

  7. 验证： 空输入、单元素、重复、负数、全相等、正序/逆序、精度和溢出。

  8. 收尾： 报告时间、辅助空间、递归栈与输出存储。

1. 复杂度与正确性 [P0]

1.1 常见增长率

  • $O(1)$：平均哈希查找、数组索引。

  • $O(log n)$：二分查找、平衡树操作、堆的推入/弹出。

  • $O(n)$：单次扫描、哈希计数。

  • $O(nlog n)$：比较排序、许多堆与扫描线算法。

  • $O(n^2)$：枚举所有二元组；$n$ 到 $10^4$ 左右通常已经过慢。

  • $O(2^n)$ 与 $O(n!)$：子集/排列搜索，往往只适合很小的 n。

常数只在渐近分析中忽略；Python 的对象分配、哈希与解释器循环成本可能让排序胜过理论上为线性、但分配很重的方案。

1.2 均摊、期望与证明方式

  • 列表 append 为均摊 $O(1)$，并非每一次最坏都为 $O(1)$。

  • 字典/集合平均 $O(1)$，病态最坏可达 $O(n)$。

  • heapq 推入/弹出 $O(log n)$；deque 两端操作 $O(1)$。

  • 循环不变量：初始化、保持、终止。

  • 归纳法：递归和 DP 常用。

  • 交换论证：贪心算法常用。

  • 割/领先论证：区间调度、最小生成树常用。

2. 数组与字符串 [P0]

2.1 前缀和与哈希

区间和等于前缀和之差。若数组含任意正负数，用哈希表记录此前前缀和频数。

def count_subarrays_sum_k(values, k):
    counts = {0: 1}
    prefix = 0
    answer = 0
    for x in values:
        prefix += x
        answer += counts.get(prefix - k, 0)
        counts[prefix] = counts.get(prefix, 0) + 1
    return answer

不变量：counts 只包含当前位置之前的前缀和。期望时间 $O(n)$，空间 $O(n)$。

2.2 双指针与滑动窗口

单调移动能够排除一整批可能性时使用双指针；连续区间的状态能随端点增删而快速更新时使用滑动窗口。

def two_sum_sorted(a, target):
    left, right = 0, len(a) - 1
    while left < right:
        total = a[left] + a[right]
        if total == target:
            return left, right
        if total < target:
            left += 1
        else:
            right -= 1
    return None

def longest_at_most_k_distinct(values, k):
    counts = {}
    left = 0
    best = 0
    for right, x in enumerate(values):
        counts[x] = counts.get(x, 0) + 1
        while len(counts) > k:
            y = values[left]
            counts[y] -= 1
            if counts[y] == 0:
                del counts[y]
            left += 1
        best = max(best, right - left + 1)
    return best

可变窗口需要“可行性随端点单调变化”。任意负数往往会破坏简单的和约束滑窗。

2.3 最大子数组与字符串模式

def max_subarray(values):
    if not values:
        raise ValueError("nonempty input required")
    ending = best = values[0]
    for x in values[1:]:
        ending = max(x, ending + x)
        best = max(best, ending)
    return best

ending 表示“必须在当前位置结束”的最佳非空子数组。用首元素初始化，才能正确处理全负数组。

  • 字符计数/异位词：Counter 或固定长度计数数组。

  • 回文：双指针；最长回文子串可从中心扩展，时间 $O(n^2)$。

  • 子串搜索：朴素 $O(nm)$；KMP/Z 算法 [P1] 为 $O(n+m)$。

  • Trie [P1] 适合前缀，但 Python 中内存开销较大。

3. 排序、二分与区间 [P0]

3.1 二分查找

先明确搜索区间是闭区间还是半开区间，以及哪一侧满足单调条件。

def binary_search(a, target):
    lo, hi = 0, len(a)          # [lo, hi)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo if lo < len(a) and a[lo] == target else -1

答案二分 [P1] 的前提是 can(x) 单调。编码前写清“左侧可行”还是“右侧可行”，避免边界死循环。

3.2 合并区间 [P0]

def merge_intervals(intervals):
    if not intervals:
        return []
    intervals = sorted(intervals)
    merged = [list(intervals[0])]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

排序后，不变量是 merged 已正确合并所有已处理区间，最后一个区间是唯一可能与当前区间重叠者。时间 $O(nlog n)$，排序外空间视实现而定。

3.3 扫描线

把区间转成“开始 +1、结束 −1”的事件并排序。必须先定义端点是否闭合，以及同一时刻开始和结束事件的顺序；这决定接触的区间是否算重叠。

4. 哈希、栈与队列 [P0]

  • 哈希表常见用途：频数、first-seen 索引、前缀状态、去重、缓存。

  • 栈常见用途：括号匹配、表达式、DFS、单调栈。

  • 队列用于 BFS；滑窗最大值可用单调 deque，每个元素最多进出一次，时间 $O(n)$。

def valid_parentheses(text):
    match = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)
        elif ch in match:
            if not stack or stack.pop() != match[ch]:
                return False
    return not stack

单调栈的关键问题：栈中保存值还是索引？单调递增还是递减？相等值弹不弹？答案由“寻找严格更大”还是“不小于”决定。

5. 链表 [P1]

5.1 反转与快慢指针

def reverse_list(head):
    prev = None
    current = head
    while current is not None:
        nxt = current.next
        current.next = prev
        prev, current = current, nxt
    return prev

快慢指针可找中点、检测环和求倒数第 k 个节点。修改指针前先保存 next；明确函数是否允许修改原链表。

6. 树、堆与并查集 [P0/P1]

6.1 二叉树遍历

from collections import deque

def level_order(root):
    if root is None:
        return []
    q = deque([root])
    levels = []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.value)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        levels.append(level)
    return levels

DFS 的递归栈最坏为树高 $O(h)$；极深树在 Python 中可能超过递归限制，此时用显式栈。

6.2 堆与 top-k

  • 动态最小/最大值、合并有序流、Dijkstra、top-k 都常用堆。

  • heapq 是最小堆；最大堆通常存负值。

  • 维护 k 个最佳元素的时间是 $O(nlog k)$，空间 $O(k)$。

6.3 并查集 [P1]

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while x != self.parent[x]:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True

路径压缩加按大小合并后，均摊复杂度近似常数 $O(alpha(n))$。

7. 图算法 [P0/P1]

7.1 BFS 与 DFS

邻接表空间为 $O(V+E)$。BFS 求无权最短路；DFS 用于连通分量、环检测、拓扑思想和回溯。

def bfs(graph, start):
    from collections import deque
    q = deque([start])
    distance = {start: 0}
    while q:
        node = q.popleft()
        for nxt in graph[node]:
            if nxt not in distance:
                distance[nxt] = distance[node] + 1
                q.append(nxt)
    return distance

标记 visited 的时机很重要：BFS 通常在入队时标记，避免同一节点重复入队。

7.2 拓扑排序 [P1]

def topological_order(graph, indegree):
    from collections import deque
    q = deque(i for i, deg in enumerate(indegree) if deg == 0)
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph[node]:
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                q.append(nxt)
    return order if len(order) == len(graph) else None

输出节点数少于 $V$ 表示有环。

7.3 最短路与最小生成树 [P1]

  • BFS：边权全为 1。

  • 0–1 BFS：边权为 0 或 1，使用 deque。

  • Dijkstra：边权非负，二叉堆复杂度 $O((V+E)log V)$。

  • Bellman–Ford：允许负边并可检测负环，复杂度 $O(VE)$。

  • Kruskal：边排序加并查集；Prim：逐步扩展割边。

8. 递归与回溯 [P0/P1]

回溯模板由四部分组成：状态、候选、合法性/剪枝、撤销选择。先说明输出规模；若所有解本身就有指数个，指数时间不可避免。

def subsets(values):
    answer = []
    path = []

    def dfs(index):
        if index == len(values):
            answer.append(path.copy())
            return
        dfs(index + 1)
        path.append(values[index])
        dfs(index + 1)
        path.pop()

    dfs(0)
    return answer

有重复元素时先排序，并在同一递归层跳过相等候选；不要误删不同层合法的重复选择。

9. 贪心算法 [P0/P1]

9.1 区间调度

选择最多不重叠区间：按结束时间升序，每次选当前最早结束且与已选集合兼容的区间。交换论证：任何最优解的第一个区间都可替换成最早结束者，不会减少后续可选空间。

9.2 何时不要贪心

“看起来局部最好”不是证明。若决策会改变未来候选且无法通过交换保持最优，尝试 DP、最短路或反例。面试中必须说出交换、领先或割性质之一。

10. 动态规划 [P0]

10.1 编码前五问

  1. 状态表示什么？

  2. 转移从哪些较小状态而来？

  3. 初始值与不可能状态是什么？

  4. 计算顺序是否保证依赖已完成？

  5. 最终答案在哪个状态，能否压缩空间？

10.2 一维 DP

def max_non_adjacent(values):
    take = float("-inf")
    skip = 0
    for x in values:
        take, skip = skip + x, max(skip, take)
    return max(skip, take)

更新多个压缩状态时必须使用旧值，通常用并行赋值。

10.3 0/1 背包

def knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in zip(weights, values):
        for cap in range(capacity, weight - 1, -1):
            dp[cap] = max(dp[cap], dp[cap - weight] + value)
    return dp[capacity]

0/1 背包容量必须倒序，避免同一物品被重复使用；完全背包则通常正序。

10.4 序列与状态机

  • 最长递增子序列：朴素 DP $O(n^2)$；tails + 二分为 $O(nlog n)$。

  • 最长公共子序列：二维 DP $O(nm)$。

  • 股票买卖类：状态通常为天数 × 持仓 × 已用交易次数。

  • 若状态是“集合”，可用 bitmask DP [P2]，但复杂度常为 $O(n2^n)$。

11. 位运算与数值算法 [P1]

11.1 位运算

  • x & (x - 1) 清除最低位的 1。

  • x & -x 取最低位的 1。

  • 异或满足自消：a ^ a = 0，适合“其余均出现偶数次”的唯一元素题。

  • Python 整数无固定字长；涉及补码或位宽时必须显式加掩码。

11.2 最大公约数与快速幂

def gcd(a, b):
    while b:
        a, b = b, a % b
    return abs(a)

def power_mod(base, exponent, mod):
    result = 1
    base %= mod
    while exponent:
        if exponent & 1:
            result = result * base % mod
        base = base * base % mod
        exponent >>= 1
    return result

欧几里得算法为 $O(log min(a,b))$；快速幂为 $O(log n)$。

11.3 数位根 [P0]

十进制正整数的反复数位和满足

$$ operatorname{dr}(n)=1+((n-1)bmod 9),qquad n>0. $$

$n=0$ 时数位根为 0。若题目要求展示过程，应写循环；若只求最终值，可用同余公式，并解释为什么模 9 不变量成立。

11.4 数值求根 [P1]

二分法只需连续函数和异号区间，稳健但线性收敛；牛顿法局部收敛快，但需导数、较好初值，并防止导数接近 0。浮点终止条件同时考虑区间宽度、函数值和最大迭代数。

12. 随机化与流式算法 [P1]

12.1 Fisher–Yates 洗牌

从后向前，对位置 i 均匀选择 $jin{0,ldots,i}$ 并交换。每个排列概率均为 $1/n!$；若 j 的范围写错，洗牌会有偏。

12.2 蓄水池抽样

未知长度流中均匀保留一个样本：第 i 个元素以概率 $1i$ 替换当前样本。保留 k 个样本时，前 k 个入池，之后第 i 个元素以概率 $ki$ 入池并均匀替换。

12.3 在线统计

均值和方差使用 Welford 更新；分位数若不能保留全量数据，需要明确是精确算法还是近似 sketch，并报告误差保证。

13. 模式识别速查

  • 连续子数组和：前缀和；含任意正负数时配哈希。

  • 有序两数关系：双指针。

  • 最长/最短连续可行区间：滑动窗口。

  • next greater/smaller：单调栈。

  • 动态 top-k：堆。

  • 无权最短路：BFS；非负权最短路：Dijkstra。

  • 依赖顺序：拓扑排序。

  • 动态连通性：并查集。

  • “方案数/最佳值”且有重叠子问题：DP。

  • 枚举所有组合：回溯并剪枝。
