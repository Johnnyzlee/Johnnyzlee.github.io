学习目标：理解 scikit-learn 的统一 Estimator API，能从基准模型开始，使用 Pipeline 安全完成预处理、训练、交叉验证、调参和评估。重点不是背模型名称，而是避免数据泄漏并解释验证设计。
系列导航：Python · NumPy · pandas

0. 机器学习代码首先是一条数据流程

一份可靠的建模答案应明确六步：

  1. 定义一行样本、特征 X 和目标 y；

  2. 在任何会“学习数据”的预处理之前切分训练集和测试集；

  3. 建立简单基准；

  4. 把填充、缩放、编码和模型放进 Pipeline；

  5. 使用适合数据结构的交叉验证与指标；

  6. 最后只在未触碰的测试集上评估一次。

scikit-learn 约定：X 通常形状为 (n_samples, n_features)，y 通常为 (n_samples,)。

# 终端安装；已有环境不需要重复执行
# python3 -m pip install scikit-learn

import numpy as np

X = np.array([[1.0], [2.0], [3.0], [4.0]])  # 4 个样本，每个 1 个特征
y = np.array([3.0, 5.0, 7.0, 9.0])         # 目标满足 y = 1 + 2x

print(X.shape)
print(y.shape)
预期输出
(4, 1)
(4,)

一维特征也必须写成二维 X。直接传 (4,) 通常会得到 “Expected 2D array” 错误。

1. Estimator API：fit、transform、predict

scikit-learn 用一组统一动词组织对象：

  • fit(X, y)：从训练数据学习参数；

  • transform(X)：使用已经学到的规则转换特征；

  • fit_transform(X, y)：在同一训练数据上先学再转换；

  • predict(X)：输出预测；

  • predict_proba(X)：部分分类器输出类别概率；

  • score(X, y)：使用模型默认指标，面试中更建议显式调用具体指标函数。

属性末尾下划线通常表示 fit 后学到的结果，例如 coef_、mean_、classes_。

from sklearn.linear_model import LinearRegression

model = LinearRegression()  # 这里只是创建配置，尚未学习任何数据
model.fit(X, y)             # 学到截距和斜率
prediction = model.predict([[5.0], [6.0]])

print("intercept:", model.intercept_)
print("coefficient:", model.coef_)
print("prediction:", prediction)
预期输出
intercept: 1.0
coefficient: [2.]
prediction: [11. 13.]

fit 只能使用训练数据。测试集可以调用 transform 和 predict，但不能参与任何 fit。

2. 切分数据并先建立基准

基准回答“复杂模型至少要超过什么”。回归可预测训练集均值，分类可预测多数类或类别先验。

from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error

X_all = np.arange(1.0, 7.0).reshape(-1, 1)
y_all = 1.0 + 2.0 * X_all.ravel()

X_train, X_test = X_all[:4], X_all[4:]  # 时间顺序：前 4 个训练，后 2 个测试
y_train, y_test = y_all[:4], y_all[4:]

baseline = DummyRegressor(strategy="mean")
baseline.fit(X_train, y_train)            # 学到训练目标均值 6
pred = baseline.predict(X_test)           # 两个测试样本都预测 6

mae = mean_absolute_error(y_test, pred)
rmse = mean_squared_error(y_test, pred) ** 0.5

print(pred)
print("MAE:", mae)
print("RMSE:", round(rmse, 4))
预期输出
[6. 6.]
MAE: 6.0
RMSE: 6.0828

测试目标是 11 和 13，所以绝对误差为 5 和 7，MAE 是 6。任何模型若连这个基准都不能稳定超过，就不值得增加复杂度。

2.1 随机切分不总是合理

train_test_split 默认随机打乱，适合近似独立同分布的样本；有时间顺序时通常应按时间切分。面板数据还要防止同一事件或重叠标签跨越训练与验证边界。

3. 标准化到底学习了什么

StandardScaler 在 fit 时学习每列训练特征的均值和标准差；transform 使用这组固定参数转换新数据。

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)  # 只转换，不能在测试集重新 fit

print("train mean:", scaler.mean_)
print("train scale:", np.round(scaler.scale_, 4))
print("scaled test:", np.round(X_test_scaled.ravel(), 4))
预期输出
train mean: [2.5]
train scale: [1.118]
scaled test: [2.2361 3.1305]

错误做法是先在全部 X_all 上 fit_transform 再切分；这样测试集分布参与了训练预处理，造成泄漏。

4. Pipeline：把预处理和模型锁在一起

from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),  # 在训练数据学习每列中位数
    ("scaler", StandardScaler()),                   # 在训练数据学习均值和尺度
    ("model", Ridge(alpha=1.0)),                    # 最后拟合带 L2 正则的线性模型
])

X_missing = np.array([[1.0], [2.0], [np.nan], [4.0]])
y_missing = np.array([3.0, 5.0, 7.0, 9.0])

pipeline.fit(X_missing, y_missing)
print(pipeline.named_steps["imputer"].statistics_)
print(np.round(pipeline.predict([[5.0]]), 4))
预期输出
[2.]
[10.1684]

中位数是 2。named_steps 让你检查 Pipeline 内学到的对象。交叉验证时，每个训练折会独立学习填充值和尺度，验证折不会泄漏进去。

4.1 为什么不能在 Pipeline 外先做特征选择

只要某一步查看了数据分布或目标——填充、缩放、类别编码、特征选择、PCA——它就必须在每个训练折内部 fit。把这些步骤放进 Pipeline 是最稳妥的默认做法。

5. 数值列与类别列：ColumnTransformer

真实表格常同时包含数值和类别。两类列需要不同预处理：

import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder
from sklearn.linear_model import LogisticRegression

data = pd.DataFrame({
    "momentum": [0.2, -0.1, 0.4, -0.3, 0.1, 0.5],
    "volatility": [0.15, 0.30, np.nan, 0.40, 0.20, 0.12],
    "sector": ["Tech", "Bank", "Tech", "Bank", "Energy", "Tech"],
})
target = np.array([1, 0, 1, 0, 0, 1])

numeric = ["momentum", "volatility"]
categorical = ["sector"]

preprocess = ColumnTransformer([
    ("num", Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler()),
    ]), numeric),
    ("cat", OneHotEncoder(handle_unknown="ignore"), categorical),
])

classifier = Pipeline([
    ("preprocess", preprocess),
    ("model", LogisticRegression(max_iter=1000)),
])
classifier.fit(data, target)

print(classifier.predict(data.iloc[[0, 1]]))
print(np.round(classifier.predict_proba(data.iloc[[0, 1]])[:, 1], 4))
典型输出
[1 0]
[0.7326 0.1765]

概率的末位可能随版本略有变化。handle_unknown=“ignore” 允许测试集出现训练时未见类别；对应的 one-hot 列全为 0，而不是抛错。

6. 交叉验证：每一折都在模拟未来未知数据

6.1 普通 KFold 与 TimeSeriesSplit

KFold 把样本分成若干折；分类常使用 StratifiedKFold 保持类别比例。时间数据使用 TimeSeriesSplit，确保训练索引在验证索引之前。

from sklearn.model_selection import TimeSeriesSplit

splitter = TimeSeriesSplit(n_splits=3)
for fold, (train_index, test_index) in enumerate(splitter.split(np.arange(8)), start=1):
    print(fold, train_index.tolist(), test_index.tolist())
预期输出
1 [0, 1] [2, 3]
2 [0, 1, 2, 3] [4, 5]
3 [0, 1, 2, 3, 4, 5] [6, 7]

金融标签若跨越多个日期，简单时间切分仍可能共享信息区间。面试中应主动讨论 gap、purge 或 embargo，而不是机械套用随机五折。

6.2 cross_val_score 评估整条 Pipeline

from sklearn.model_selection import cross_val_score

X_cv = np.arange(1.0, 13.0).reshape(-1, 1)
y_cv = 1.0 + 2.0 * X_cv.ravel()

linear_pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("model", LinearRegression()),
])

scores = cross_val_score(
    linear_pipeline,
    X_cv,
    y_cv,
    cv=TimeSeriesSplit(n_splits=3),
    scoring="neg_mean_absolute_error",
)

print(np.round(scores, 6))
print("mean MAE:", round(-scores.mean(), 6))
预期输出
[-0. -0. -0.]
mean MAE: 0.0

scikit-learn 评分约定“越大越好”，所以损失指标使用负号。报告时取负数还原 MAE，并同时报告各折离散度。

7. 如何选择第一批模型

从容易解释的基准开始，再根据失败模式增加复杂度：

  • 回归基准：DummyRegressor，再试 LinearRegression、Ridge、Lasso；

  • 分类基准：DummyClassifier，再试 LogisticRegression；

  • 非线性表格数据：决策树、随机森林、梯度提升；

  • 高维稀疏数据：正则化线性模型通常是强基准；

  • 降维/可视化：PCA；聚类：KMeans，但无监督结果仍需稳定性与业务解释。

不要说“随机森林一定更好”。模型选择取决于样本量、特征类型、非线性、噪声、可解释性、训练预算和部署约束。官方 Choosing the Right Estimator 流程图可用于复习。

7.1 正则化直觉

Ridge 在平方误差之外惩罚系数平方，降低方差；alpha 越大，系数通常越接近 0。Lasso 使用绝对值惩罚，可产生精确 0 系数，但高度相关特征下选择可能不稳定。

8. 调参：Pipeline 参数使用双下划线

from sklearn.model_selection import GridSearchCV

search = GridSearchCV(
    estimator=pipeline,
    param_grid={
        "imputer__strategy": ["mean", "median"],
        "model__alpha": [0.1, 1.0, 10.0],
    },
    cv=2,
    scoring="neg_mean_absolute_error",
)
search.fit(X_missing, y_missing)

print(search.best_params_)
print(type(search.best_estimator_).__name__)
典型输出
{'imputer__strategy': 'mean', 'model__alpha': 0.1}
Pipeline

名称 model__alpha 表示 Pipeline 中名为 model 的步骤的 alpha 参数。小样本的最优值没有意义；这里仅展示接口。真实研究应预先定义搜索空间和指标，保留最终测试集，避免反复看测试结果。

9. 指标：先问错误代价是什么

9.1 回归指标

from sklearn.metrics import r2_score

y_true = np.array([1.0, 2.0, 10.0])
y_pred = np.array([1.0, 4.0, 7.0])

print("MAE:", mean_absolute_error(y_true, y_pred))
print("RMSE:", round(mean_squared_error(y_true, y_pred) ** 0.5, 4))
print("R2:", round(r2_score(y_true, y_pred), 4))
预期输出
MAE: 1.6666666666666667
RMSE: 2.0817
R2: 0.7329

  • MAE 线性惩罚误差，单位与目标相同，较容易解释；

  • RMSE 更强调大误差；

  • $R^2$ 相对于均值基准衡量平方误差，样本外可以为负；

  • 量化预测还应考虑 rank IC、分组收益、换手率、成本与时序稳定性。

9.2 分类指标

from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

y_true = np.array([1, 1, 1, 0, 0, 0])
y_pred = np.array([1, 0, 1, 0, 1, 0])

print("accuracy:", accuracy_score(y_true, y_pred))
print("precision:", precision_score(y_true, y_pred))
print("recall:", recall_score(y_true, y_pred))
print("F1:", f1_score(y_true, y_pred))
预期输出
accuracy: 0.6666666666666666
precision: 0.6666666666666666
recall: 0.6666666666666666
F1: 0.6666666666666666

类别不平衡时 accuracy 可能误导。ROC-AUC 衡量整体排序；正类罕见时 PR-AUC 常更有信息。阈值应依据误报和漏报代价选择，而不是默认 0.5。

10. 系数、特征重要性与解释限制

  • 线性模型系数受特征尺度影响；比较前应理解标准化。

  • 相关特征会使单个系数不稳定，即使总体预测稳定。

  • 树的 impurity importance 可能偏好连续或高基数特征。

  • permutation importance 必须在未用于拟合的数据上计算，并受相关特征影响。

  • “模型使用某特征”不是因果结论。预测关联、交易可用性和因果解释是不同问题。

11. 高频泄漏与复现错误

  • 全数据填充/标准化后再切分；正确做法是切分后由 Pipeline 在训练折 fit。

  • 用测试集选择特征、阈值或超参数；测试集因此不再是最终评估。

  • 随机打乱时间序列；未来观测进入过去训练。

  • 同一实体或事件同时出现在训练和验证中；需要 GroupKFold 或按事件分组。

  • 特征包含目标之后才知道的信息；例如用收盘数据预测同一收盘成交。

  • 不固定 random_state，也不记录版本和数据快照。

  • 只报告最好的一折，不报告平均、离散度和样本外基准。

12. 量化面试中的完整回答模板

面对“预测未来收益”的题目，可以按这个顺序口述：

  1. 一行是一个资产-日期；目标是未来 $h$ 期收益，特征在交易时点之前可得。

  2. 按时间排序，保留最后一段作为最终测试；若标签重叠，加入 purge/gap。

  3. 建立零收益或训练均值基准。

  4. 用 Pipeline 放置缺失填充、缩放、类别编码和模型。

  5. 训练期内部使用 TimeSeriesSplit；调参指标与业务目标一致。

  6. 报告每折指标、测试指标、IC、换手与成本敏感性。

  7. 做泄漏审计、特征稳定性、残差与不同市场阶段检查。
