0.1 最小运行环境

把下面内容保存为 hello.py，然后在终端运行 python3 hello.py：

name = "quant"                 # 创建字符串，并把名字 name 指向它
score = 0.81234                 # 创建浮点数
print(f"{name}: {score:.3f}")  # :.3f 表示保留三位小数
预期输出
quant: 0.812

print 负责显示；函数没有显式 return 时返回 None。面试平台通常已经准备好 Python 环境，不要在答案中写安装命令。

1. 名字、对象与类型：Python 最重要的心智模型

Python 变量不是“装数值的盒子”，而是指向对象的名字。赋值 b = a 通常不会自动复制对象。

prices = [100, 102, 101]  # 创建一个可变 list
alias = prices            # alias 和 prices 指向同一个 list
alias.append(104)         # 原地修改这个共享 list

print(prices)             # prices 也会看到新增的 104
print(alias is prices)    # is 检查是否为同一个对象
预期输出
[100, 102, 101, 104]
True

如果需要互不影响的浅复制，写 copy = prices.copy()。浅复制只复制最外层容器；嵌套列表仍可能共享内部对象。

1.1 可变与不可变

  • 不可变：int、float、bool、str、tuple。所谓“修改”其实会创建新对象并重新绑定名字。

  • 可变：list、dict、set 以及多数数据科学对象。方法可能直接改动原对象。

  • == 比较值是否相等；is 比较是否为同一个对象。检查空值写 x is None。

x = 10
y = x
x = x + 1              # 创建整数 11；不会改变 y 指向的整数 10

print(x, y)
print(x == y)
预期输出
11 10
False

2. 数字、布尔值与浮点数

2.1 常用运算

cash = 17
lot_size = 5

lots, remainder = divmod(cash, lot_size)  # 同时得到整除商和余数
power = 2 ** 3                            # 2 的 3 次方
floor_value = -7 // 3                     # 向负无穷取整，不是向 0 截断

print(lots, remainder)
print(power)
print(floor_value)
预期输出
3 2
8
-3

比较运算返回 bool。and 与 or 会短路：一旦结果已经确定，右侧表达式不会执行。

2.2 为什么不能直接比较浮点数

十进制小数通常不能被二进制浮点数精确表示。

import math

raw = 0.1 + 0.2
print(raw)                              # 显示底层舍入误差
print(raw == 0.3)                       # 直接比较失败
print(math.isclose(raw, 0.3, rel_tol=1e-12))
预期输出
0.30000000000000004
False
True

面试中应说明容差的业务含义。金额可能需要 decimal.Decimal；科学计算通常使用浮点数和明确容差。

3. 四种核心容器

3.1 list：有序且可修改

returns = [0.02, -0.01, 0.03]
returns.append(0.01)          # 在尾部加入一个元素，均摊 O(1)
last = returns.pop()          # 删除并返回最后一个元素，O(1)
middle = returns[1:3]         # 切片不包含右端点 3，并创建新 list

print(last)
print(middle)
print(returns)
预期输出
0.01
[-0.01, 0.03]
[0.02, -0.01, 0.03]

列表索引是 $O(1)$；在头部插入或删除是 $O(n)$。队列应使用 collections.deque，不要反复 list.pop(0)。

3.2 tuple：不可修改的记录

quote = ("AAPL", 214.5)
symbol, price = quote       # 解包：按位置取出两个字段
print(symbol)
print(price)
预期输出
AAPL
214.5

元组中的所有元素都可哈希时，元组可以作为字典键。单元素元组必须写 (value,)，末尾逗号不能省略。

3.3 dict：键到值的映射

weights = {"AAPL": 0.4, "MSFT": 0.6}
weights["GOOG"] = 0.0                   # 新增键值对
apple_weight = weights.get("AAPL", 0.0) # 键存在时返回对应值
missing = weights.get("TSLA", 0.0)      # 键不存在时返回默认值

print(apple_weight)
print(missing)
print(list(weights.keys()))
预期输出
0.4
0.0
['AAPL', 'MSFT', 'GOOG']

字典查找、插入和删除平均为 $O(1)$。直接写 weights[“TSLA”] 会在键不存在时抛出 KeyError；是否应使用默认值取决于业务语义。

3.4 set：唯一元素与快速成员检查

tradable = {"AAPL", "MSFT", "GOOG"}
portfolio = {"AAPL", "TSLA"}

print("AAPL" in tradable)       # 平均 O(1) 成员检查
print(portfolio & tradable)      # 交集
print(portfolio - tradable)      # 只在 portfolio 中的元素
预期输出
True
{'AAPL'}
{'TSLA'}

集合本身无排序语义；需要稳定展示时使用 sorted(result)。空集合写 set()，因为 {} 是空字典。

4. 条件、循环与配对遍历

4.1 if elif else

ret = -0.035

if ret > 0.02:
    label = "large gain"
elif ret < -0.02:
    label = "large loss"
else:
    label = "small move"

print(label)
预期输出
large loss

缩进决定代码块。通常使用四个空格，不要混用 Tab 与空格。

4.2 enumerate 和 zip 到底在做什么

symbols = ["AAPL", "MSFT", "GOOG"]
returns = [0.02, -0.01, 0.03]

for position, (symbol, ret) in enumerate(zip(symbols, returns), start=1):
    # zip 每次给出一对 (symbol, ret)；enumerate 再附加从 1 开始的位置
    print(position, symbol, f"{ret:.1%}")
预期输出
1 AAPL 2.0%
2 MSFT -1.0%
3 GOOG 3.0%

zip 默认在最短输入耗尽时停止。若两个序列长度本应相同，现代 Python 可使用 zip(a, b, strict=True) 让长度错误立刻暴露；面试平台版本未知时，也可先显式检查长度。

4.3 break 与 continue

continue 跳过本轮剩余语句；break 立即结束整个循环。只有在控制流更清晰时才使用它们。

values = [3, -1, 5, 0, 8]
first_zero = None

for index, value in enumerate(values):
    if value < 0:
        continue                 # 忽略负数，继续下一轮
    if value == 0:
        first_zero = index
        break                    # 已找到第一个 0，不再继续扫描

print(first_zero)
预期输出
3

5. 函数：把输入、规则和输出说清楚

5.1 返回简单收益率

def simple_returns(prices):
    """Return consecutive simple returns; require positive prices."""
    if len(prices) < 2:                      # 至少两个价格才能产生一个收益率
        return []
    if any(price <= 0 for price in prices):  # 防止无意义或除零输入
        raise ValueError("prices must be positive")

    result = []
    for previous, current in zip(prices, prices[1:]):
        result.append(current / previous - 1.0)
    return result

answer = simple_returns([100, 102, 101])
print([round(x, 4) for x in answer])
预期输出
[0.02, -0.0098]

逐行理解：

  • prices[1:] 是从第二个价格开始的新列表。

  • zip(prices, prices[1:]) 形成 (100,102) 与 (102,101) 两对相邻价格。

  • 函数内部用完整精度计算，只有显示时才 round；不要过早舍入。

  • 输入长度为 $n$ 时扫描一次，时间复杂度 $O(n)$，输出占用 $O(n)$ 空间。

5.2 参数、默认值与关键字参数

def clip(value, lower=-1.0, upper=1.0):
    return max(lower, min(value, upper))

print(clip(1.7))                    # 使用两个默认边界
print(clip(1.7, upper=2.0))         # 只覆盖 upper，意图更清楚
预期输出
1.0
1.7

不要把可变对象作为默认值：

def append_value(value, output=None):
    if output is None:       # 每次调用都创建新的列表
        output = []
    output.append(value)
    return output

print(append_value(1))
print(append_value(2))
预期输出
[1]
[2]

若写成 output=[]，这个列表只在函数定义时创建一次，多次调用会意外共享历史数据。

6. 推导式、生成器与常用标准库

6.1 推导式不是魔法循环

returns = [0.02, -0.01, 0.03, -0.04]

positive_bps = [round(ret * 10_000) for ret in returns if ret > 0]
# 对每个正收益率乘 10,000，把小数收益换成基点；负收益被过滤

print(positive_bps)
预期输出
[200, 300]

推导式适合“一个表达式 + 一个简单过滤条件”。逻辑超过两层时，普通循环通常更易读、也更容易调试。

6.2 Counter、defaultdict 与 deque

from collections import Counter, defaultdict, deque

trades = [("AAPL", 10), ("MSFT", 5), ("AAPL", 7)]

trade_count = Counter(symbol for symbol, _ in trades)
quantity_by_symbol = defaultdict(int)
for symbol, quantity in trades:
    quantity_by_symbol[symbol] += quantity

recent = deque(maxlen=2)
for trade in trades:
    recent.append(trade)              # 超过长度 2 时自动丢弃最旧元素

print(trade_count["AAPL"])
print(dict(quantity_by_symbol))
print(list(recent))
预期输出
2
{'AAPL': 17, 'MSFT': 5}
[('MSFT', 5), ('AAPL', 7)]

6.3 heapq：为什么 top-k 不必完整排序

import heapq

scores = [0.12, -0.03, 0.44, 0.19, 0.31]
top_two = heapq.nlargest(2, scores)  # 只选最大的两个值
print(top_two)
预期输出
[0.44, 0.31]

完整排序需要 $O(nlog n)$；维护大小为 $k$ 的堆通常是 $O(nlog k)$。当 $k$ 很小而 $n$ 很大时差异明显。

7. 排序、异常、文件与测试

7.1 多级排序键

rows = [
    {"date": "2026-01-02", "score": 0.2, "id": "B"},
    {"date": "2026-01-02", "score": 0.5, "id": "A"},
    {"date": "2026-01-01", "score": 0.1, "id": "C"},
]

ordered = sorted(
    rows,
    key=lambda row: (row["date"], -row["score"], row["id"]),
)
# 先按日期升序；同一天按 score 降序；仍相同则按 id 升序

print([(row["date"], row["id"]) for row in ordered])
预期输出
[('2026-01-01', 'C'), ('2026-01-02', 'A'), ('2026-01-02', 'B')]

sorted(data) 返回新列表；data.sort() 原地修改并返回 None。Python 排序是稳定的，相等键保持原相对顺序。

7.2 只捕获你预计会发生的异常

text = "12.5"

try:
    value = float(text)          # 字符串不能解析时抛出 ValueError
except ValueError:
    value = None

print(value)
预期输出
12.5

不要使用 except Exception: pass 静默吞掉所有错误。文件应交给上下文管理器关闭：

with open("prices.csv", "r", encoding="utf-8") as file:
    header = file.readline().strip()  # 离开 with 后文件自动关闭

7.3 最小测试清单

对每个函数至少考虑：空输入、单元素、重复值、负数、全相等、已排序、逆序、极大数、错误类型。可以把期望写成断言：

assert simple_returns([]) == []
assert simple_returns([100]) == []
assert math.isclose(simple_returns([100, 110])[0], 0.1)

若断言失败，Python 会抛出 AssertionError；全部通过时不显示任何内容。

8. 完整面试示例：固定长度滑动平均

题目：给定数字序列和窗口长度 $k$，返回每个连续窗口的平均值。

先看朴素方法：每个窗口都重新求和，长度为 $n$ 时需要约 $O(nk)$。更好的方法维护窗口和：新元素进入时加上，旧元素离开时减去，总时间 $O(n)$。

def moving_average(values, k):
    if k <= 0:
        raise ValueError("k must be positive")
    if k > len(values):
        return []

    window_sum = sum(values[:k])       # 第一个窗口的和，O(k)
    averages = [window_sum / k]

    for right in range(k, len(values)):
        entering = values[right]       # 新进入窗口的元素
        leaving = values[right - k]    # 同时离开窗口的元素
        window_sum += entering - leaving
        averages.append(window_sum / k)

    return averages

result = moving_average([1, 2, 3, 6, 8], 3)
print(result)
预期输出
[2.0, 3.6666666666666665, 5.666666666666667]

手工检查三个窗口：

  • [1,2,3] 的平均值为 $2$；

  • [2,3,6] 的平均值为 $11/3$；

  • [3,6,8] 的平均值为 $17/3$。

复杂度：初始化 $O(k)$，其余每个元素只进出一次，因此总时间 $O(n)$；除输出外额外空间 $O(1)$。

9. 量化研究中常见的纯 Python 模板

9.1 在线均值：数据不必全部存进内存

stream = [2.0, 4.0, 8.0]
count = 0
mean = 0.0

for value in stream:
    count += 1
    mean += (value - mean) / count  # 加入新样本后更新均值
    print(count, round(mean, 4))
预期输出
1 2.0
2 3.0
3 4.6667

这个算法只使用 $O(1)$ 额外空间，也比反复累加极大数后再相除更适合流式场景。

9.2 可复现的随机模拟

import random

rng = random.Random(42)                 # 局部随机数生成器，不污染全局状态
tosses = [rng.choice(["H", "T"]) for _ in range(6)]
print(tosses)
预期输出（标准 CPython）
['H', 'H', 'T', 'H', 'H', 'H']

固定种子只保证可复现，不会让样本“更随机”。大规模数组模拟应使用 NumPy 的 Generator，见下一篇教程。
