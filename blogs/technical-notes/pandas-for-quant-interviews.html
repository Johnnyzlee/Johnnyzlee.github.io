学习目标：把 pandas 理解为“带标签的二维数据操作系统”，能安全地完成选择、清洗、分组、连接、整形与时间序列特征构造。所有例子使用小型交易面板，并明确展示操作前后表格。
系列导航：Python · NumPy · scikit-learn

0. 先理解 DataFrame，而不是先背 API

DataFrame 是二维表：每一行通常是一条观测，每一列是一个变量，Index 给行加标签。Series 是带标签的一维数组，也是 DataFrame 的一列。

量化数据常见的“长表”结构是一行一个 (date, asset) 观测：

import pandas as pd

trades = pd.DataFrame({
    "date": pd.to_datetime([
        "2026-01-02", "2026-01-02", "2026-01-03",
        "2026-01-03", "2026-01-04",
    ]),
    "asset": ["A", "B", "A", "B", "A"],
    "sector": ["Tech", "Bank", "Tech", "Bank", "Tech"],
    "price": [100.0, 50.0, 102.0, 49.0, 101.0],
    "volume": [10.0, 20.0, 15.0, None, 12.0],
    "signal": [0.3, -0.2, 0.5, 0.1, None],
})

print(trades.to_string(index=False))  # index=False 只是不显示左侧行号
print("shape:", trades.shape)
预期输出
      date asset sector  price  volume  signal
2026-01-02     A   Tech  100.0    10.0     0.3
2026-01-02     B   Bank   50.0    20.0    -0.2
2026-01-03     A   Tech  102.0    15.0     0.5
2026-01-03     B   Bank   49.0     NaN     0.1
2026-01-04     A   Tech  101.0    12.0     NaN
shape: (5, 6)

表有 5 行、6 列。NaN 表示缺失浮点值，不等于 0。

实际项目先检查：shape、列名、dtypes、缺失值、重复键、日期范围和数值分布。字符串看似日期时，不要依赖字典序，显式 pd.to_datetime。

版本说明： 上面展示 pandas 3.x 的常见 dtype；pandas 2.x 可能显示 datetime64[ns] 和 object。名称不同不改变这里的检查原则。

1.1 唯一键检查

duplicate_key = trades.duplicated(["date", "asset"], keep=False)
print(duplicate_key.any())
预期输出
False

这说明 (date, asset) 在示例中唯一。若应唯一却出现 True，不要直接 drop_duplicates；先查清重复来自修订记录、错误连接还是源数据问题。

2. 选择：loc 按标签，iloc 按位置

2.1 选择列、行和条件

prices = trades["price"]                       # 单列 -> Series
small_table = trades[["date", "asset", "price"]]  # 多列 -> DataFrame

liquid = trades.loc[
    trades["volume"].gt(12),                   # 行条件：volume > 12
    ["date", "asset", "volume"],              # 要返回的列
]

print(type(prices).__name__)
print(liquid.to_string(index=False))
预期输出
Series
      date asset  volume
2026-01-02     B    20.0
2026-01-03     A    15.0

gt(12) 等价于 > 12，但链式方法有时更便于组合。缺失值与 12 比较得到 False，因此不会入选。

2.2 iloc 与切片边界

print(trades.iloc[0:2, 0:3].to_string(index=False))
# iloc 使用整数位置；0:2 取第 0、1 行，不包含位置 2
预期输出
      date asset sector
2026-01-02     A   Tech
2026-01-02     B   Bank

loc 的标签切片通常包含结束标签，而 iloc 像 Python 切片一样不包含结束位置。面试中先说清你使用的是标签还是位置。

2.3 安全创建新列

selected = trades.loc[trades["asset"].eq("A")].copy()
selected.loc[:, "notional"] = selected["price"] * selected["volume"]

print(selected[["date", "asset", "notional"]].to_string(index=False))
预期输出
      date asset  notional
2026-01-02     A    1000.0
2026-01-03     A    1530.0
2026-01-04     A    1212.0

使用 .copy() 表明要独立修改筛选结果；使用 .loc 明确赋值目标。避免 df[df[“x”]>0][“y”] = … 这种链式赋值。

3. 缺失值、类型转换与重复值

3.1 缺失值处理必须带业务假设

filled = trades.copy()
filled["volume"] = filled["volume"].fillna(0.0)  # 假设缺失成交量表示没有成交
dropped = trades.dropna(subset=["signal"])       # 只要求 signal 非缺失

print(filled["volume"].tolist())
print(dropped[["date", "asset", "signal"]].to_string(index=False))
预期输出
[10.0, 20.0, 15.0, 0.0, 12.0]
      date asset  signal
2026-01-02     A     0.3
2026-01-02     B    -0.2
2026-01-03     A     0.5
2026-01-03     B     0.1

上面的 0 填充只是示例假设。若缺失表示“数据未到达”，填 0 会制造虚假观测。必须记录每列的缺失规则。

3.2 类型转换

raw = pd.Series(["10", "bad", "30"])
numeric = pd.to_numeric(raw, errors="coerce")  # 无法解析的 bad 变成 NaN

print(numeric.tolist())
预期输出
[10.0, nan, 30.0]

errors=“coerce” 方便清洗，但会隐藏原始错误值。实际项目应同时保存失败掩码，例如 raw[numeric.isna() & raw.notna()]。

4. groupby：agg 与 transform 的区别

4.1 agg 每组变成摘要行

sector_summary = (
    trades.groupby("sector", observed=True)
    .agg(
        observations=("price", "size"),
        mean_price=("price", "mean"),
        mean_signal=("signal", "mean"),
    )
    .reset_index()
)

print(sector_summary.to_string(index=False))
预期输出
sector  observations  mean_price  mean_signal
  Bank             2        49.5        -0.05
  Tech             3       101.0         0.40

mean 默认忽略 NaN，所以 Tech 的 mean_signal 用 0.3 和 0.5 计算。agg 把每个行业缩减成一行。

4.2 transform 保持原行数

with_group_mean = trades.copy()
with_group_mean["sector_mean_signal"] = (
    with_group_mean.groupby("sector", observed=True)["signal"].transform("mean")
)
with_group_mean["demeaned_signal"] = (
    with_group_mean["signal"] - with_group_mean["sector_mean_signal"]
)

print(
    with_group_mean[["asset", "sector", "signal", "demeaned_signal"]]
    .to_string(index=False)
)
预期输出
asset sector  signal  demeaned_signal
    A   Tech     0.3            -0.10
    B   Bank    -0.2            -0.15
    A   Tech     0.5             0.10
    B   Bank     0.1             0.15
    A   Tech     NaN              NaN

transform 返回与原表同长度的 Series，因此能直接成为新列。apply 更灵活，但行为、性能和返回索引更难预测；优先使用已有的 agg、transform 和向量化方法。

5. merge：先定义键的唯一性

metadata = pd.DataFrame({
    "asset": ["A", "B"],
    "country": ["US", "HK"],
    "market_cap": [500.0, 120.0],
})

panel = trades.merge(
    metadata,
    on="asset",                 # 两张表都使用 asset 作为连接键
    how="left",                 # 保留 trades 的所有行
    validate="many_to_one",     # 左表可重复，右表 asset 必须唯一
    indicator=True,             # 临时记录每行从哪里匹配而来
)

print(panel[["asset", "country", "_merge"]].drop_duplicates().to_string(index=False))
print("rows before/after:", len(trades), len(panel))
预期输出
asset country _merge
    A      US   both
    B      HK   both
rows before/after: 5 5

validate=“many_to_one” 是重要的安全带：如果右表有重复 asset，连接会抛错，而不是悄悄把行数放大。连接后应检查行数、未匹配率和关键数值总量。

连接类型：

  • left：保留左表；特征映射最常见；

  • inner：只保留双方匹配行，可能无声丢样本；

  • outer：保留双方全部键，适合对账；

  • concat：按某个轴直接拼接，不按键匹配。

6. 长表与宽表：pivot 与 melt

wide_price = trades.pivot(index="date", columns="asset", values="price")
print(wide_price.to_string())
预期输出

date
2026-01-02  100.0  50.0

pivot 要求每个 (date, asset) 最多一个价格；若键重复会报错。pivot_table 可以聚合重复值，但必须显式选择 aggfunc，否则可能掩盖数据错误。

print(long_price.to_string(index=False))

7. 时间序列：排序、shift、pct_change 与 rolling

任何分组时间运算前先按实体和时间排序。

panel = trades.sort_values(["asset", "date"]).copy()
grouped = panel.groupby("asset", group_keys=False)

panel["ret_1d"] = grouped["price"].pct_change(fill_method=None)
panel["signal_lag1"] = grouped["signal"].shift(1)
panel["price_mean_2"] = grouped["price"].transform(
    lambda s: s.rolling(window=2, min_periods=2).mean()
)

print(
    panel[["date", "asset", "price", "ret_1d", "signal_lag1", "price_mean_2"]]
    .to_string(index=False)
)
预期输出
      date asset  price    ret_1d  signal_lag1  price_mean_2
2026-01-02     A  100.0       NaN          NaN           NaN
2026-01-03     A  102.0  0.020000          0.3         101.0
2026-01-04     A  101.0 -0.009804          0.5         101.5
2026-01-02     B   50.0       NaN          NaN           NaN
2026-01-03     B   49.0 -0.020000         -0.2          49.5

逐列解释：

  • pct_change 在每个资产内部用当前价格除以前一价格；首行没有前值，所以 NaN。

  • shift(1) 把上一期信号移到当前行；用于确保预测时只使用已经知道的信息。

  • rolling(2) 当前窗口包含当前价格与前一期价格。若这个特征要用于当期开盘前预测，可能还需整体再 shift(1)。

7.1 构造未来收益目标

panel["fwd_ret_1d"] = grouped["price"].transform(
    lambda s: s.shift(-1).div(s).sub(1.0)
)

print(panel[["date", "asset", "price", "fwd_ret_1d"]].to_string(index=False))
预期输出
      date asset  price  fwd_ret_1d
2026-01-02     A  100.0    0.020000
2026-01-03     A  102.0   -0.009804
2026-01-04     A  101.0         NaN
2026-01-02     B   50.0   -0.020000
2026-01-03     B   49.0         NaN

这里时点 $t$ 的目标使用 $t+1$ 价格。最后一行没有未来价格，因此目标缺失。特征发布时间、成交时点、复权方式和目标区间必须共同审计。

8. 截面排名与一个小型因子流程

为展示同一天多个资产，使用另一张小表：

factor = pd.DataFrame({
    "date": pd.to_datetime(["2026-01-02"] * 3 + ["2026-01-03"] * 3),
    "asset": ["A", "B", "C", "A", "B", "C"],
    "signal": [0.2, -0.1, 0.5, 0.4, 0.3, -0.2],
    "fwd_ret": [0.01, -0.02, 0.03, 0.02, 0.01, -0.01],
})

factor["signal_rank"] = factor.groupby("date")["signal"].rank(
    method="average", pct=True
)
daily_ic = factor.groupby("date")[["signal", "fwd_ret"]].apply(
    # Spearman 相关就是“两个变量各自排名后”的 Pearson 相关
    lambda g: g["signal"].rank().corr(g["fwd_ret"].rank()),
)

print(factor.to_string(index=False))
print("daily IC:")
print(daily_ic)
预期输出
      date asset  signal  fwd_ret  signal_rank
2026-01-02     A     0.2     0.01     0.666667
2026-01-02     B    -0.1    -0.02     0.333333
2026-01-02     C     0.5     0.03     1.000000
2026-01-03     A     0.4     0.02     1.000000
2026-01-03     B     0.3     0.01     0.666667
2026-01-03     C    -0.2    -0.01     0.333333
daily IC:
date
2026-01-02    1.0
2026-01-03    1.0
dtype: float64

分组前只选取相关数值列，可以避免把分组键意外传入自定义函数。显式先 rank() 也避免依赖 SciPy 这一可选包。这个玩具数据故意完全单调，真实 IC 不会如此完美。

9. 性能与正确性

  • 优先列运算、内置 groupby 方法和连接；避免逐行 iterrows()。

  • apply 不是自动加速器；能用向量化、agg 或 transform 就不用 apply。

  • 大表先缩小列和行，再连接或分组；检查内存可用 df.memory_usage(deep=True)。

  • 将重复字符串转 category 可能省内存，但连接与排序语义要先确认。

  • 不要依赖隐式排序。时间操作前显式 sort_values。

  • 每次 merge 检查键唯一性、validate、行数变化和未匹配率。

  • 每个滚动或滞后特征都写清“在时点 $t$ 到底可不可以知道”。

10. 面试检查表

  1. 一行代表什么？主键是什么？

  2. 每列的 dtype 和缺失语义是什么？

  3. 选择使用标签还是位置？

  4. 分组操作是缩减行数的 agg，还是保持行数的 transform？

  5. 连接关系是一对一、一对多还是多对多？

  7. 结果行数、日期范围和数值总量是否符合预期？
